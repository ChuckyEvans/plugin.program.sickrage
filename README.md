SickRage Control
================
A Kodi addon for managing SickRage — control your TV show downloads directly from Kodi.

## Features
 - Manage shows (add/delete, pause/resume, search by name)
 - Change episode and season status
 - View upcoming episodes
 - View download history
 - View backlog
 - View/delete failed downloads
 - Browse recommended shows (TVmaze or Episodate)
 - Add recommended shows directly to SickRage
 - Customizable date/time format

## Requirements
 - Kodi 21+ (Python 3.11)
 - SickRage backend running and accessible on your network

## Install
 - Download the latest release zip from [GitHub](https://github.com/ChuckyEvans/plugin.program.sickrage/releases)
 - In Kodi: Add-ons → Install from zip file
 - Configure the addon with your SickRage URL and API key
